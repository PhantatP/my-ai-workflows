# Domain profiles

Profiles define what correctness means after Core has classified and routed the
task:

- [BUILD](build/routing.md): verify the artifact, behavior, actual change set,
  and risk controls.
- [RESEARCH](research/routing.md): verify source quality, evidence coverage,
  contradiction handling, and uncertainty.
- [LEARN](learn/routing.md): verify accurate teaching, reconstruction,
  application, and independent transfer.

Mixed tasks may use more than one profile at different assurance levels. Main
integrates the segments without imposing identical process on each one.
