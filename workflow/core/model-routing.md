# Adaptive model routing

Model selection is separate from assurance. Choose the cheapest class able to
perform the operation: `STRONG` for difficult judgment, synthesis, diagnosis,
or adversarial review; `BALANCED` for ordinary implementation and integration;
`ECONOMY` for bounded mechanical work. Classes are provider-neutral shorthand,
not universal rankings; adapters map them to models.

Escalate for insufficient reasoning, judgment, context, instruction-following,
precision, or synthesis; return to cheaper capability once the hard decision is
bounded. Prefer stronger capability to another agent for reasoning limits, but
use an independent instance for independence. Avoid switches whose handoff cost
exceeds savings; retain the model holding needed context. Record material
transitions; do not claim unsupported automatic switching.
