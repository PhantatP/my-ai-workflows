# Portable handoff

Use a concise Markdown [Task Packet](../templates/task-packet.md) for
cross-platform moves, substantial context loss, or persistent bounded
delegation. Include goal, context, facts/unknowns, constraints, decisions,
evidence, domains, level, verification, artifacts, and next action; optionally
include alternatives, risks, learner/research/BUILD state, and capability.
Distinguish evidence, facts, inferences, and unverified notes. Packets transfer
state, not trust.
