# Portable handoff

Cross-platform handoffs use a concise Markdown Task Packet. Use [the template](../templates/task-packet.md) when a task moves between execution surfaces, resumes after substantial context loss, or requires a bounded delegation with persistent state.

Minimum content:

- Goal
- Current context
- Known facts
- Unknowns
- Constraints
- Decisions already made
- Relevant evidence
- Domain or domains
- Current assurance level
- Required verification
- Artifacts and references
- Next intended action

Optional content includes rejected alternatives, risk flags, open questions, learner state, research confidence, BUILD change summary, and recommended model capability.

Keep packets concise enough to transfer without reconstructing a conversation. Distinguish quoted evidence, established facts, inferences, and unverified assistant notes. A Task Packet transfers state; it does not increase the trust of its contents.
