# BUILD compatibility entry point

The V2.3 Core router is [`../core/routing.md`](../core/routing.md). The
canonical BUILD-specific procedure is
[`../profiles/build/routing.md`](../profiles/build/routing.md).

This path is retained so V2.2.1 adapters do not silently lose their routing
instructions during migration. The executable trigger policy remains
[`triggers.yaml`](triggers.yaml).
