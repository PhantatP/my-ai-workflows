# My AI Workflows V2.5 / V2.5.1 (experimental)

Portable workflow: Core routes BUILD, RESEARCH, and LEARN; profiles define
correctness; adapters map capability; Markdown information policy is separate.
V2.5 adds bounded Artifact Lifecycle/Provenance; V2.5.1 adds progressive
context and single-owner policy. V2.4 interaction stays in LEARN, not a
cross-domain layer. PLAN/GRILL are optional experimental presets; Phase 3 is
closed and Phase 4 admits only genuine-use evidence.

BUILD retains deterministic trigger scanning and fail-closed guarding;
RESEARCH is minimal; LEARN carries the bounded interaction experiment.

```text
core/ routing, assurance, models, information
profiles/ domain correctness     adapters/ platform mappings
templates/ portable state        bin/ and enforcement/ BUILD tools
routing/ trigger policy          agents/ delegation contracts
experiments/ protocols/evidence  future/ deferred inventory
```

Adopt the adapter, `workflow/`, and active skills. Projects may extend
`routing/triggers.yaml` without conflating mechanical evidence and judgment.
Scan before edits and actual changes after; `.workflow/log.txt` is ignored
operational evidence. Capability limits remain in `adapters/capabilities.yaml`.
