# V2.3 compatibility entry point

The platform-neutral principles are now domain-general and live in
[`core/principles.md`](core/principles.md). Read that file together with
[`core/routing.md`](core/routing.md), [`core/assurance.md`](core/assurance.md),
and the relevant domain profile.

This path remains as a compatibility bootstrap for repositories and adapters
that adopted V2.2.1. BUILD-specific mechanical floors remain authoritative in
`routing/triggers.yaml` and `profiles/build/routing.md`.
