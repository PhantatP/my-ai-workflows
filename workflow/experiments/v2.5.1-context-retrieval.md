# V2.5.1 — Context Retrieval and Policy Compression

**Status:** Experimental  
**Scope:** BUILD, RESEARCH, LEARN, and general Assistant information logistics.

## Hypothesis

Progressive retrieval and single-source policy ownership can reduce active
context, cached/fresh reads, latency, and policy maintenance without increasing
missing-context rework or reducing correctness. The target is minimum
sufficient context, not minimum context.

## Validation protocol

Use real tasks and compare, where practical, with a pre-V2.5.1 baseline:

1. Workflow maintenance: relevant policy only; historical experiments stay cold.
2. Finance refresh: canonical company note → stale claims → targeted new
   evidence → original reports only where required.
3. BUILD change: relevant repository state → dependent code as uncertainty
   appears; no whole-project read by default.
4. LEARN continuation: current learner state and concept only.
5. Large source: canonical summary and targeted sections before full-source read.

Record when available: task/domain, outcome quality, fresh and cached input,
output, files inspected, full files and large sources opened, expansions,
rework from missing context, unnecessary reads, and behavior regression.

## Failure checks

Watch for under-retrieval, over-retrieval, stale-summary trust, premature stop,
context drift, policy duplication, compression regression, cold-policy leakage,
and token reduction that is erased by rework. Expand when evidence is missing,
confidence is insufficient, sources conflict, state may be stale, verification
is required, a dependency is explicit and necessary, or the user requests
broader inspection.

## Promotion gate

Promote only if real cross-domain use shows materially lower context/policy
usage, stable or improved correctness, low missing-context rework, effective
canonical summaries, selective large-source reads, reduced duplication, and
simple reliable execution while local rules remain selectively retrievable.
Otherwise keep experimental, revise, or reject. Do not add a retrieval router
or scoring system unless simpler progressive retrieval demonstrably fails.
